# The Merge Music

Mobile-first social music platform by EJAY PAPI.

## MVP
- Home discovery feed
- Live audio panel experience
- Artist and producer battles with voting
- Creator profiles
- Music review and submission flows
- Responsive red, black, and metallic brand system

## Local development
```bash
npm install
npm run dev
```

Built with React, TypeScript, Vite, Tailwind CSS, and shadcn-compatible components.
